# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

A personal knowledge base collecting learnings, frameworks, and best practices for building with AI at scale. This is a documentation-only repo—no build system, tests, or application code. All content is Markdown.

## Structure

- `ai-engineering-maturity-model.md` — Tool-agnostic capability maturity model for AI-assisted engineering (6 levels, framework landscape comparison)
- `claude-code/` — Claude Code workflow patterns (7 levels of adoption, skills, hooks, GSD framework, agent teams)
- `prompt-engineering/` — Prompting techniques across AI models
- `agent-orchestration/` — Multi-agent coordination strategies
- `case-studies/` — Real-world implementation examples
- `inbox/` — Staging area for raw content being considered for inclusion (not part of the published KB)

## Conventions

- Content is written in a conversational, direct tone with contractions and short paragraphs
- Use em-dashes (—) instead of regular dashes for parenthetical phrases
- No emojis or semicolons
- Attribution required when adapting external frameworks (see `7-levels-of-claude-code.md` for example)
- New content sections should include a `README.md` in their directory describing what's inside and listing resources
